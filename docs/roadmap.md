## 1.1 (2026-11-25, решения владельца)

Дизайн — [plans/2026-11-25-platina-1.1-design.md](plans/2026-11-25-platina-1.1-design.md), план —
[plans/2026-11-25-platina-1.1.md](plans/2026-11-25-platina-1.1.md).

- **PS4**: списки PS5 и PS4 (`TrophyTitle.isSupported`), «PS4» в строке игры, Game Help (функция
  PS5) для PS4 не запрашивается.
- **Друзья** — только прогресс: Профиль → Друзья (кто впереди в скольких общих играх), экран друга
  (общие игры, оба прогресса, больший разрыв первым), раздел «Друзья» в игре. `FriendsSync`:
  не чаще раза в 12 часов, профили раз в неделю; друг, скрывший трофеи, помечен, а не роняет
  список. Кэш, не iCloud.
- **Мгновенные трофеи**: включаются в Настройках, сервер получает свой доступ к PSN (второй код
  из входа) и шлёт пуш о каждом трофее, даже когда приложение не запущено; несколько за проверку
  — одним уведомлением, платина — отдельно (docs/assistant.md [§9](archive/plans/2026-11-20-stages.md)). Нужен ключ APNs (секреты
  `APNS_KEY_P8`, `APNS_KEY_ID`), App Privacy — «User ID» (docs/app-store.md [§2](domains/psn.md)).

iPad и Mac: приложение для iPhone и iPad, на Mac идёт приложение для iPad.
