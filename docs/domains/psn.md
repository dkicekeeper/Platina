# PlayStation Network: откуда берутся данные


## PlayStation Network

У Sony нет публичного API. Используем неофициальный, на котором работают PSNProfiles, Exophase
и библиотеки `psn-api` (JS) и `PSNAWP` (Python):

1. Вход в аккаунт Sony через вход PlayStation Store во встроенном окне: человек входит как
   обычно, на странице Sony. Когда Sony возвращает в Store, приложение берёт сессию Sony
   (`npsso`) и меняет её на код клиента PlayStation App: страница OAuth-авторизации
   (`ca.account.sony.com/api/authz/v3/oauth/authorize`) с этой сессией сразу перенаправляет на
   `com.scee.psxandroid.scecompcall://redirect?code=…`. Пароль приложение не видит. Не сразу
   страница входа клиента PlayStation App: у части людей она не грузится (риски ниже).
2. Код меняем на access токен (час) и refresh токен (около двух месяцев).
3. Refresh токен лежит в Keychain. Когда он истекает, просим войти снова.
4. Запасной путь на случай, если вход в окне Safari не сработает (у владельца страница входа
   клиента PlayStation App не грузится: «Время соединения с сервером истекло»; войти в
   PlayStation Store и взять токен получилось): вставить токен NPSSO
   вручную (войти на playstation.com в Safari, открыть `ca.account.sony.com/api/v1/ssocookie`).
5. Запросы идут **прямо с телефона** на `m.np.playstation.com`. Наш сервер токены Sony не видит.
6. Язык названий и описаний трофеев — заголовок `Accept-Language` по языку приложения.
7. Пока показываем только списки трофеев PS5 (`trophyTitlePlatform` содержит `PS5`,
   `npServiceName = trophy2`); код от платформы не зависит, PS4 включается фильтром.

Что даёт PSN:

| Данные | Откуда |
|---|---|
| Список игр с трофеями: прогресс %, сколько каких трофеев есть и получено, платформа, когда обновлялось | `trophy/v1/users/me/trophyTitles` |
| Трофеи игры: название, описание, иконка, тип, скрытый или нет, группы DLC, редкость % | `trophy/v1/npCommunicationIds/{id}/trophyGroups/all/trophies` |
| Мои трофеи: получен ли, дата, прогресс счётчика на PS5 («37 из 50») | `trophy/v1/users/me/npCommunicationIds/{id}/trophyGroups/all/trophies` |
| Уровень трофеев профиля, итоги по типам | `trophy/v1/users/me/trophySummary` |
| Время в игре (с точностью до секунды), первый и последний запуск, число запусков, обложки | `gamelist/v2/users/me/titles` (только PS4 и PS5) |
| Что запущено на консоли прямо сейчас | `userProfile/v1/internal/users/me/basicPresences` |

Чего в PSN нет: подсказок, сложности, времени до платины, списка пропускаемых трофеев,
дорожной карты. Это делает ИИ с веб-поиском ([§5](plati.md)).

## Риски

- API неофициальный: Sony может его поменять. Весь доступ к PSN живёт в одном модуле (`PSNKit`),
  с тестами на сохранённых JSON-ответах, чтобы поломку было видно сразу и чинить в одном месте.
- Формально это против пользовательского соглашения Sony. Для личного приложения риск
  небольшой. Для App Store есть риск отказа на ревью (хотя похожие приложения там есть):
  перед публикацией отдельно проверим, как такие приложения проходят ревью.
- У Sony есть неопубликованные лимиты запросов. Синхронизация инкрементальная и бережная ([§6](../architecture.md)).
- Страница входа клиента PlayStation App может не грузиться (у владельца и у пользователей
  GOG Galaxy: «Время соединения с сервером истекло»). Запасной путь — токен NPSSO из входа в
  PlayStation Store.
- DNS сети может подменять адреса серверов Sony: приложение переключается на свой
  зашифрованный DNS (`NameResolution`).
- Модели библиотек (psn-api) расходятся с настоящими ответами: сверяем с
  [andshrew/PlayStation-Trophies](https://github.com/andshrew/PlayStation-Trophies/blob/master/docs/APIv2.md),
  сбои пишем в системный журнал.
- В приложении не используем логотипы и названия PlayStation как бренд, только данные.
- App Store (решение 2026-11-23 — публикуем): ревью может отказать из-за неофициального API
  PSN; в заметках для ревью — как устроен вход и что токены остаются на телефоне. Тексты
  гайдов не копируем: шаги — пересказ своими словами со ссылкой на источник. Картинки из
  гайдов показываем как превью ссылки: грузятся с сайта источника (у нас не хранятся), с
  подписью и переходом на это место гайда; на сервере — выключатель по источнику
  (`IMAGE_SOURCES`), чтобы убрать картинки сайта без релиза, если сайт или ревью против. Перед
  публикацией — письма PowerPyx, PSNProfiles и Stratege с просьбой о разрешении.
- Защита Sony от ботов (Kasada на странице входа) может однажды не пустить встроенное окно
  входа; запасной путь — токен NPSSO. Хэши запросов Game Help могут смениться — подсказки
  молча пропадут до обновления.
