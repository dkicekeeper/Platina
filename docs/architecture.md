# Архитектура приложения


```
Platina/
├── ios/
│   ├── project.yml            XcodeGen (проект генерируется, .xcodeproj не в git)
│   ├── Platina/               приложение: экраны, навигация
│   ├── PlatinaWidgets/        Live Activity и виджеты
│   └── Packages/PlatinaKit/   SPM-пакет
│       ├── PSNKit             вход, токены, клиент API, DTO, Game Help (без UI)
│       ├── PlatinaCore        логика без UI и SwiftData: план синхронизации, время, статистика
│       ├── PlatinaStore       SwiftData, синхронизация, сессии, Плати на телефоне, Game Help
│       ├── PlatinaAssistant   клиент сервера, цикл инструментов, App Attest
│       └── PlatinaShared      общее с расширением: Live Activity, снимок виджетов
├── server/assistant/          Cloudflare Worker (TypeScript, @anthropic-ai/sdk)
└── docs/
```

- **Swift 6**, iOS 26+, DesignKit по точной версии; workflow «DesignKit update» поднимает
  версию, как в Tenra и Dalada. Сборка — Xcode 27 (iOS 27 SDK).
- **iPad и macOS впереди** (этап 10): логика живёт в пакете без UIKit, экраны — SwiftUI без
  проверок «это iPhone» и без жёстких размеров экрана; то, что есть только на iPhone (Live
  Activity, Dynamic Island), — за проверкой доступности.
- **Хранение**: SwiftData. Данные PSN можно скачать заново; свои данные (сессии, заметки,
  цели, чаты, статусы игр) синхронизируются через iCloud (CloudKit).
- **Синхронизация**: `trophyTitles` сортируется по времени изменения, так что трофеи качаем
  только для изменившихся игр. Повторы с паузами при ошибках и лимитах. Фоновое обновление
  (`BGAppRefreshTask`) раз в несколько часов, локальное уведомление о новых трофеях.
- **Безопасность**: токены Sony только в Keychain, на наш сервер не уходят.
- **Локализация**: String Catalog, русский (основной) и английский с первого дня.
- **Тесты**: `PSNKit` и синхронизация на сохранённых JSON-ответах (swift-testing).
- **Сборка**: этот контейнер на Linux, SwiftUI здесь не компилируется. Компилятор — CI на macOS
  (GitHub Actions), как у DesignKit: пушим, читаем логи. TestFlight-сборка из CI.

## Модель данных (черновик)

| Сущность | Поля |
|---|---|
| `Profile` | accountId, onlineId, аватар, уровень, прогресс до следующего, итоги по типам |
| `Game` | npCommunicationId, npTitleIds, название, иконка/обложка, платформы, есть ли DLC, трофеи по типам (всего и получено), прогресс %, время, первый/последний запуск, число запусков, мой статус, lastUpdated |
| `TrophyGroup` | id (`default`, `001`...), название, иконка, счётчики |
| `Trophy` | id, группа, тип, название, описание, иконка, скрытый, редкость %, получен, дата, прогресс/цель счётчика; мои поля: цель, пропускаемый, заметка, шаг дорожной карты |
| `Guide` | игра, сложность, часы, прохождения, онлайн, пропускаемые, глюки, источники, дата |
| `RoadmapStep` | гайд, порядок, название, текст, трофеи, пройден |
| `TrophyTip` | трофей, текст подсказки, источники |
| `PlaySession` | игра, начало, конец, время по таймеру, время по PSN, цели, полученные трофеи, прогресс до/после, заметка, резюме ИИ |
| `Conversation` / `Message` | игра (или общий), сообщения, вызовы инструментов |
| `Walkthrough` (кэш сервера) | игра, язык, главы: название, пропускаемое, выборы, коллекционки, трофеи главы, источники; прохождений нужно |
| `WalkthroughStep` (кэш сервера) | глава, порядок, тип (путь, предмет, выбор, невозврат, трофей, босс), текст, трофеи, источник, спойлер ли |
| `WalkthroughProgress` (свои данные, iCloud) | игра, текущая глава, сделанные шаги, пропущенные (для «Уборки»), дата |
