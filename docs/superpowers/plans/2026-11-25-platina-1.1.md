# Platina 1.1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** PS4 games, friends compared by progress in shared games, and a push for every trophy
with the app closed.

**Architecture:** Three independent parts, in this order, each shippable alone. PS4 and friends
live in the app (PSNKit → PlatinaStore cache → screens); instant trophies add a Durable Object per
subscriber to the Worker in `server/assistant`, which polls PSN with its own grant and sends APNs.

**Tech Stack:** Swift 6 / SwiftUI / SwiftData / DesignKit (iOS 26), swift-testing (PSNKit on
Linux, PlatinaStore on the simulator in CI); TypeScript Cloudflare Worker, Durable Objects
(SQLite), vitest.

**Spec:** docs/superpowers/specs/2026-11-25-platina-1.1-design.md

## Global Constraints

- Every PSN request lives in PSNKit, tested on JSON fixtures through `MockTransport`; no network in
  tests.
- Every UI string a key in `ios/Platina/Localizable.xcstrings`, `ru` and `en`.
- Every view that shows data has a skeleton; DesignKit components only (CLAUDE.md block).
- Friends data is cache (not iCloud): no CloudKit schema change.
- PSN requests: friends refreshed at most every 12 h unasked; the watcher polls presence every 5
  min idle, trophy titles every 60 s while playing, every 10 min when presence is hidden.
- Server writes are App Attest-signed (`authenticate` in `src/index.ts`); secrets never in logs.
- APNs topic `dakacom.Platina`, team `SY2L2VMQP7`; secrets `APNS_KEY_P8`, `APNS_KEY_ID`,
  `TOKEN_KEY`.

## Review Focus

- A friend who hides trophies (PSN 403): shows "hides trophies", never fails the whole list.
- A game only one side has: not "shared"; a friend with no shared games: the empty state.
- A PS4 game in Game Help: no request, no section.
- The first watcher check after subscribing: records, sends nothing (no flood of old trophies).
- A refused refresh token or an APNs 410: one "sign in again" push at most, the watcher stops.
