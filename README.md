# Platina

Трекер трофеев PlayStation с ИИ-ассистентом Плати: каждая игра — путь к платине и 100%, а Плати
ведёт по ней «за руку», глава за главой.

- План, решения и этапы: [docs/PLAN.md](docs/PLAN.md)
- Для разработки (и для Claude): [CLAUDE.md](CLAUDE.md)
- Плати (приложение ↔ сервер): [docs/assistant.md](docs/assistant.md)
- Сборка и TestFlight: [docs/testflight.md](docs/testflight.md)

Сейчас: этапы 0–4 сделаны, приложение работает на iPhone с настоящим аккаунтом PSN (вход через
PlayStation Store, синхронизация, подсказки PlayStation), сервер Плати развёрнут, сборки идут в
TestFlight. Дальше ([docs/PLAN.md §9](docs/PLAN.md#9-этапы)):

5. Проверка на устройстве.
6. Прохождение «за руку»: главы и шаги, прогресс, сессия с текущей главой.
7. Наглядный чат: карточки, чек-листы, быстрые ответы.
8. Без рук: Live Activity с кнопкой ✓, Siri, озвучка.
9. «Где я?» по фото экрана.
10. iPad и macOS.
11. App Store.
